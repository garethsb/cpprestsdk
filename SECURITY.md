# Security

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately instead, with the "Report a vulnerability" button on this repository's Security tab. Only the maintainers can see the report. We will work on the fix with you in a private security advisory, and publish the advisory when the fix is released.

Please include the version or commit you tested, the platform, and the steps or code that reproduce the problem.

## Supported Versions

Security fixes go to the default branch and the next release made from it. Microsoft no longer supports its releases of cpprestsdk, up to 2.10.19.

## Dependencies

Please report a vulnerability in a dependency, such as OpenSSL, Boost, zlib or websocketpp, to that project. Let us know as well if cpprestsdk needs a change because of it, for example a new minimum version.
